title: "Get a collaboration"
description: "Returns a collaboration that is accessible to the organization."
---

**GET** `https://workspace.passionfroot.me/api/v1/collaborations/{collaborationId}`

Returns a collaboration that is accessible to the organization.

> **Authentication:** Bearer API key<br />**Required scope:** `read:collaborations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collaborationId` | path | `string` | Yes |  |
| `include` | query | `campaign` | No | Set to `campaign` to include campaign details. |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/v1/collaborations/{collaborationId}' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | The collaboration. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `404` | Resource not found or not accessible to this organization. |
| `429` | Rate limit exceeded. |
