**GET** `https://workspace.passionfroot.me/api/v1/creators/{creatorId}`

Returns one creator when the organization has a qualifying collaboration with them.

> **Authentication:** Bearer API key<br />**Required scope:** `read:collaborations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `creatorId` | path | `string` | Yes |  |
| `include` | query | `channels` | No | Set to `channels` to include channels and metrics. |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/v1/creators/{creatorId}' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | The creator. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `404` | Resource not found or not accessible to this organization. |
| `429` | Rate limit exceeded. |
