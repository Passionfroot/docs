title: "List conversation messages"
description: "Returns the typed conversation timeline newest first. Reading messages does not mark the conversation as read."
---

**GET** `https://workspace.passionfroot.me/api/v1/conversations/{conversationId}/messages`

Returns the typed conversation timeline newest first. Reading messages does not mark the conversation as read.

> **Authentication:** Bearer API key<br />**Required scope:** `read:conversations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | Yes |  |
| `createdAfter` | query | `string` | No | Include messages created on or after this date or timestamp. |
| `limit` | query | `integer` | No |  |
| `cursor` | query | `string` | No | Opaque cursor returned by the previous page. |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/v1/conversations/{conversationId}/messages' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | A page of timeline events. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `404` | Resource not found or not accessible to this organization. |
| `429` | Rate limit exceeded. |
