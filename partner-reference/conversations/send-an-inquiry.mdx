**POST** `https://workspace.passionfroot.me/api/v1/inquiries`

Sends initial outreach to a creator and creates a conversation and inquiry collaboration when needed.

> **Authentication:** Bearer API key<br />**Required scope:** `write:conversations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | `string` | No | Unique key for one logical write. Reuse the key and identical body for retries. |

### JSON body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `creatorId` | `string (uuid)` | Yes | Creator receiving the inquiry. |
| `text` | `string` | Yes |  |
| `campaignId` | `string (uuid)` | No | Optional organization campaign. |

```json
{
  "creatorId": "418f65a3-8981-4b31-aadf-9b399ab64475",
  "text": "We would love to work together on our fall launch."
}
```

### Example request

```bash
curl --request POST --url 'https://workspace.passionfroot.me/api/v1/inquiries' --header 'Authorization: Bearer YOUR_API_KEY' --header 'Idempotency-Key: YOUR_UNIQUE_KEY' --header 'Content-Type: application/json' --data '{"creatorId":"418f65a3-8981-4b31-aadf-9b399ab64475","text":"We would love to work together on our fall launch."}'
```

## Responses

| Status | Description |
| --- | --- |
| `201` | Inquiry sent. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `404` | Resource not found or not accessible to this organization. |
| `409` | The operation conflicts with current state or an identical write is in progress. |
| `422` | The request is well formed but cannot be processed. |
| `429` | Rate limit exceeded. |
| `500` | Unexpected server failure. Re-read state before retrying a write. |

### 201 response

```json
{
  "data": {
    "conversationId": "conv_abc",
    "messageId": "msg_abc",
    "collaborationId": "collab_abc"
  }
}
```

For shared error behavior, see [Authentication](/guides/authentication) and [Rate limits](/guides/rate-limits).
