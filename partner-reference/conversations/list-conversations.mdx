**GET** `https://workspace.passionfroot.me/api/v1/conversations`

Returns conversations ordered by most recent message activity. Archived and blocked conversations are included unless filtered out.

> **Authentication:** Bearer API key<br />**Required scope:** `read:conversations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `updatedAfter` | query | `string` | No | Include conversations with message activity on or after this date or timestamp. |
| `creatorId` | query | `string` | No | Return the conversation with this creator, if one exists. |
| `isUnread` | query | `boolean` | No |  |
| `isArchived` | query | `boolean` | No |  |
| `isBlocked` | query | `boolean` | No |  |
| `q` | query | `string` | No | Case-insensitive search across names and message text. |
| `include` | query | `creator` | No | Set to `creator` to include creator details. |
| `limit` | query | `integer` | No |  |
| `cursor` | query | `string` | No | Opaque cursor returned by the previous page. |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/v1/conversations' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | A page of conversations. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `429` | Rate limit exceeded. |
