title: "Get a collaboration"
description: "Returns one collaboration owned by the creator."
---

**GET** `https://workspace.passionfroot.me/api/creators/v1/collaborations/{collaborationId}`

Returns one collaboration owned by the creator.

> **Authentication:** Bearer API key<br />**Required scope:** `creator:read:collaborations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collaborationId` | path | `string` | Yes |  |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/creators/v1/collaborations/{collaborationId}' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | The collaboration. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `404` | Resource not found or not owned by this creator. |
| `429` | Rate limit exceeded. |
