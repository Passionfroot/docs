title: "List partners"
description: "Returns brands with which the creator has a qualifying collaboration."
---

**GET** `https://workspace.passionfroot.me/api/creators/v1/partners`

Returns brands with which the creator has a qualifying collaboration.

> **Authentication:** Bearer API key<br />**Required scope:** `creator:read:collaborations`

## Request

### Parameters

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `integer` | No |  |
| `cursor` | query | `string` | No | Opaque cursor returned by the previous page. |

### Example request

```bash
curl --request GET --url 'https://workspace.passionfroot.me/api/creators/v1/partners' --header 'Authorization: Bearer YOUR_API_KEY'
```

## Responses

| Status | Description |
| --- | --- |
| `200` | A page of partners. |
| `400` | Invalid parameters or body. |
| `401` | Missing, invalid, expired, or revoked API key. |
| `403` | The key lacks access or the required scope. |
| `429` | Rate limit exceeded. |

### 200 response

{
  "data": [
    {
      "id": "partner_xyz",
